What one agent found before it was sold

Built for a program that offers startups a free year of hosted authentication.

I ran it on the last nine Y Combinator batches before the first call.

1,285 companies scanned. 409 had no login yet, so the decision was still open. 297 were live on a competitor. 31 were already customers and would have been wasted outreach.

Two independent detection methods, agreeing 96% of the time where both fired. Public signals only. No credentials submitted, no contact with any company.

The same screen on funded companies: of 1,976 that raised in one summer, 265 were software companies inside the program's gates. 13% of a raw list was worth the team's time. The agent removes the other 87% before it reaches the inbox.
